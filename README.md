## How to Run

1. Open the folder `security-marketplace`
2. Double-click `index.html` (or right-click → Open with → Chrome / Edge / Firefox)

No server needed — works offline with browser localStorage.

## Full Features

### Homepage
- Professional hero + login/register form (Customer or Company)
- Services overview, How it Works, sample companies
- Footer with ADLE WEBDESIGNS credit

### Customer Side
- Dashboard with recent requests
- **Security Personnel** – browse officers + submit request (duration in days/months)
- **CCTV Installations** – browse packages + request
- **Search** – search officers & services by keyword/location
- **My Requests** – track status (Pending / Accepted / Rejected)

### Company Side
- Dashboard with stats
- **My Officers** – add/remove officers (name, age, gender, specialty, intro, rate, photo)
- **My Services** – add CCTV packages, VIP, etc. with prices
- **Incoming Requests** – accept or reject customer requests
- **Company Profile** – edit address, locations, bank details, about

## Demo Flow

1. Open `index.html`
2. Register as **Security Company** → fill location & address
3. Add officers + add CCTV service
4. Logout → Register as **Customer**
5. Browse Personnel or Installations → submit request
6. Logout → login as Company → see request in Incoming Requests → Accept/Reject
